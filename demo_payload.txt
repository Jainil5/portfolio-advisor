API STATUS
==========
This project currently exposes Python service functions rather than an HTTP REST API.
The examples below describe the service-level request and response contract.

1. Get news for one ticker
--------------------------
Function:
news_for_ticker(ticker_or_name, limit=5)

Basic query:
{
  "ticker_or_name": "RELIANCE.NS",
  "limit": 5
}

Company-name query:
{
  "ticker_or_name": "Adani Energy Solutions",
  "limit": 5
}

Response type:
list[dict]

Response example:
[
  {
    "title": "Reliance announces quarterly results",
    "url": "https://example.com/reliance-results",
    "snippet": "Reliance reported its latest quarterly results.",
    "source": "Example Finance",
    "published": "2026-08-17T09:00:00Z"
  }
]

2. Refresh news for all active stocks
-------------------------------------
Function:
news_for_all(limit=5)

Basic query:
{
  "limit": 5
}

Response type:
dict[str, list[dict]]

Response example:
{
  "RELIANCE.NS": [
    {
      "title": "Reliance announces quarterly results",
      "url": "https://example.com/reliance-results",
      "snippet": "Reliance reported its latest quarterly results.",
      "source": "Example Finance",
      "published": "2026-08-17T09:00:00Z"
    }
  ],
  "ADANIENSOL.NS": [
    {
      "title": "Adani Energy Solutions market update",
      "url": "https://example.com/adani-update",
      "snippet": "A market update for Adani Energy Solutions.",
      "source": "Example Finance",
      "published": "2026-08-17T09:00:00Z"
    }
  ]
}

Saved JSON shape:
{
  "updated_at": "2026-08-17T09:00:00+00:00",
  "news": {
    "RELIANCE.NS": ["News 1", "News 2"],
    "ADANIENSOL.NS": ["News 1", "News 2"]
  }
}

3. Query through the finance agent
----------------------------------
Function:
query_stock_info(query: str) -> str

Basic query:
"Show the top news for Reliance and Adani Energy Solutions"

Response type:
str

Run tests:
venv/bin/python -m pytest -q test/test_api.py
